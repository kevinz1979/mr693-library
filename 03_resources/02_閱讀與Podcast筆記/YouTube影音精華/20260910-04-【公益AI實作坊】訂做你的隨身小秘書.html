【公益AI實作坊】訂做你的隨身小秘書

Key Takeaways (重點整理)

  • 本工作坊目標為打造「全模態 AI 高階秘書」，整合 LINE 官方帳號、Google Apps Script (GAS)、Google 試算表 (Sheets)、Google 雲端硬碟 (Drive)、Google 日曆 (Calendar) 以及 Google Gemini 大語言模型 API，實現名片辨識存檔、多聯絡人建檔、歷程查詢、對話摘要與日曆行程自動排定等功能。
  • 整個串接系統的核心在於成功取得並配置「6 把關鍵金鑰/代碼」，包含 Google Drive 資料夾 ID、Google Sheets ID、Google 日曆 ID、Gemini API Key、LINE Messaging API Channel Access Token 及 LINE User ID。
  • 呼叫 Gemini API 時需特別注意模型版本限制，講者指出訓練資料庫停留在 2024 年的 1.5 版本目前可能無法正常調用，需指定最新支援的模型版本，且需在 Google AI Studio 正確綁定信用卡帳單以啟用付費額度。
  • 部署 GAS 網頁應用程式時，必須將執行身分設定為「我 (Me)」，並將存取權限設為「所有人 (Anyone)」，最後將產出的 Web App URL (結尾為 /exec) 填入 LINE Developers 的 Webhook URL 並開啟 Webhook 接收功能。

Summary (內容摘要)

本次實作課程由社群版主帶領 13 位學員進行「全模態 AI 高階秘書」的實作開發。該系統旨在解決商務交流後名片整理不易與對話紀錄遺忘的痛點。使用者只需在 LINE 官方帳號拍照上傳名片，AI 便會自動進行視覺與文字辨識，將公司、姓名、電話、職稱等分欄寫入 Google 試算表；即使單張名片包含多人資訊亦能精準拆分儲存，並支援透過文字或語音進行歷史聯絡記錄查詢與自動新增 Google 日曆約會行程。

課程的核心環節聚焦於「外部 API 與各平台代碼的取得與串接」，而非從零手寫程式碼。講者引導學員逐步完成六大金鑰的收集：從 Google 雲端硬碟資料夾網址截取 Drive ID、從試算表網址截取 Sheets ID、從 Google 日曆設定取得結尾為 @group.calendar.google.com 的日曆 ID；在 Google AI Studio 建立專案、取得 Gemini API Key 並綁定信用卡付費帳戶；以及在 LINE Developers 後台建立 Messaging API 頻道，取得長效 Channel Access Token 與 Basic Settings 中的專屬 User ID。

在程式部署階段，學員將整合好六大金鑰的程式碼貼入 Google 試算表內建的 Google Apps Script (GAS) 編輯器中。講者強調金鑰填入時前後必須保留單引號且不得有贅字或空白。完成部署並通過 Google 安全存取授權後，學員將 GAS 的 Webhook 網址回填至 LINE 後台並啟用 Webhook 與媒體檔案接收權限。針對部分學員遇到的「系統發生錯誤」或無回應狀況，多數源於 API 帳單綁定問題、Webhook 網址未包含 /exec 結尾或回應設定衝突，後續將針對細節調整與除錯再加開延伸課程。

Action Items (待辦事項 / 關鍵行動)

  • 全體學員：確認已將 6 項關鍵金鑰（Drive ID、Sheets ID、Calendar ID、Gemini API Key、LINE Channel Access Token、LINE User ID）妥善備份於本機純文字記事本中。
  • 尚未取得 User ID 或 API 報錯的學員：檢查 Google AI Studio 信用卡帳單設定狀態，並於 LINE Developers 的 Basic Settings 頁面確認專屬 User ID。
  • 全體學員：檢查 LINE Official Account Manager 後台設定，務必開啟 Webhook 接收、關閉自動回應訊息，並確認允許接收圖片與媒體檔案。
  • 全體學員：確認 GAS 部署網址正確填入 LINE Webhook URL，並檢查網址結尾是否包含 /exec。
  • 講師 (社群版主)：針對遭遇付費授權錯誤、User ID 遺失及程式細部微調需求之學員，規劃並發送下一堂 3-4 小時的進階排錯與客製化通知。
