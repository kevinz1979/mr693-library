AI 摘要報告

Key Takeaways (重點整理)

  • 美股關稅判決非實質利多，而是大幅推升「不確定性」：美國最高法院雖否決以 IEEPA 課徵關稅，但川普有 98% 至 99% 的機率絕不可能退還關稅，後續勢必改採 232、301 或 122 條款（如 10% 全球性關稅）等碎片化法條各個擊破，國際貿易摩擦恐將升溫。
  • 資安與軟體股遭市場過度恐慌拋售：Anthropic 推出 Cloud Code Security 僅屬靜態代碼掃描（SAST）工具，與 Cloudflare（防禦流量與 API 守衛）及 CrowdStrike（伺服器即時阻擋防護）的核心業務截然不同；軟體並未消亡，而是朝向「API 化」發展，且新工具加入將使整體潛在市場（TAM）擴大百倍至千倍。
  • 地緣政治風險升溫，需提防市場延遲反應：北約與波蘭領導人已呼籲僑民儘速撤出伊朗，區域衝突機率大幅提升；投資人不應以輕率態度看待，需警惕如 2022 年烏俄戰爭引發長達一年修正的連鎖效應。
  • 開工台股籌碼具支撐，開盤預期持平：富台指與台指期逆價差維持在 10 點以內，若國際盤無劇烈波動將平盤開出；年前退場的槓桿資金與丙種墊款資金預期將在 1 至 2 週內迅速回補部位。
  • 投資勝率與人生哲學：人生本質是在打發時間並創造回憶；投資則應追求分散配置（10 至 15 檔標的）並嚴格控管下檔風險，單一標的過度重押容易在市場恐慌或極端行情中迷失。

Summary (內容摘要)

講者回顧此次農曆春節為其畢業以來最放鬆的假期，因小孩成長能自理，加上年前適度調降槓桿與部位，體會到運用資本與科技（如透過 AI 進行 Vibe Coding 編寫遊戲輔助程式、以 Gemini 解決硬體設定）所帶來的效率與純粹樂趣。如同張家倫所言，「人生就是不停在打發時間」，關鍵在於找到有趣且能留下深刻記憶的事物，而非將人生全數耗費於難以留存細節的單一盯盤之中。

針對開工後總體經濟與市場展望，台指期與富台指價差在 10 點以內，預期開盤無重大變化。籌碼面上，年前避險的槓桿資金與場外丙種資金預期於開工後 1 至 2 週內快速回補。然而，海外總經風險顯著上升：一是伊朗衝突升溫可能帶來的外溢效應；二是美國最高法院否決 IEEPA 關稅法源，市場雖以短線反彈解讀，但實質上是將市場最厭惡的「不確定性」再次拉高。川普不可能認錯退出，反而會改採更凌碎的 232、301 或 122 條款（Universal 10% 關稅）持續推進，引發其他貿易夥伴更強烈的對抗與報復。

在科技趨勢方面，市場從過去「不信 AI」轉變為「過度相信 AI 能取代一切」，導致軟體與資安股遭到非理性拋售。講者指出，AI 時代的應用軟體核心是走向「API 化」而非消失，使用者介面（UI）權重降低，改由 Agent 呼叫執行並依結果（Result-based）計費。針對 Anthropic 的代碼檢測更新，其本質為 SAST 靜態掃描，與 Cloudflare 的流量阻擋及 CrowdStrike 的即時入侵防禦不可混為一談。如同黃仁勳所述「軟體已死」並不合邏輯，新技術誕生將使整體 TAM 規模大幅擴張，即使個別企業市占率下滑，獲利與營收規模仍遠超以往，投資人應維持客觀理性，避免在市場恐慌修正時做出情緒化決策。

Action Items (待辦事項 / 關鍵行動)

  • 投資人部位管理：面對外部地緣政治（伊朗局勢）與美國關稅政策的高度不確定性，買進節奏應放慢、賣出調節可稍微放大，確保心理處於不恐慌的舒適狀態。
  • 盤面籌碼追蹤：持續觀察開盤後 1 至 2 週內台股丙種與槓桿資金的回補動能，確認國際盤勢是否穩定。
  • 科技與資安股檢視：理性評估軟體與資安類股（如 Cloudflare、CrowdStrike）的實質護城河，逢市場因 AI 恐慌全面通殺、估值修正之際，尋找優質標的長線布局機會。
  • 資訊過濾與分析：停止過度依賴新聞媒體或單一券商目標價，投資分析應回歸公司財務數據與實質獲利成長性，做好嚴格的下檔風險控管。
