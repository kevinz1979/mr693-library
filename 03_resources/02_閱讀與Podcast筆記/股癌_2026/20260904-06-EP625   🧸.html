Key Takeaways (重點整理)

  • 法人共識股集體重挫與資金輪動：台股加權指數跌幅僅 0.46% 且櫃買創新高之際，市場長期共識股如健策、貿聯、智邦（2345）、台光電與鴻勁（7769）同步出現修正，顯示市場資金偏好可能正在轉向新主流，投資人不應僅依賴市場短線找理由的小作文來做判斷。
  • NVIDIA 跨足 Storage Server 推出 ICMS 架構：黃仁勳揭露 Inference Context Memory Platform (ICMS)，藉由 BlueField DPU 驅動儲存伺服器，將運算範疇從 Compute、Switch 正式拓展至 Storage，主打全機櫃整合方案以突破傳統摩爾定律瓶頸。
  • 群聯（Phison）切入 NVIDIA 供應鏈與 pSLC 技術：CES 展場拆解顯示 NVIDIA Switch Tray 搭載群聯控制晶片，採用將 512GB 的 TLC 顆粒模擬為 pSLC（Pseudo-SLC）至約 160-170GB 的設計，藉由犧牲容量換取高速存取與大幅延長使用壽命。
  • Agentic AI 驅動 KV Cache 下放儲存層：進入代理人 AI（Agentic AI）與長上下文（Context）推理時代，AI 面臨記憶體負載過大與「斷片」痛點，NVIDIA 透過 GPU Direct Storage 將準熱資料下放至 SSD 暫存，帶動儲存伺服器從單純「報價漲跌題材」轉向「結構性架構升級題材」。
  • 投資研究與操作思維警示：高品質產業報告應聚焦於最新技術變革對既有供應鏈的實質影響；面對信貸 20% 買進正 2（槓桿型 ETF）的提問，講者強調過去十年台股為全球最強市場，切忌以「看後照鏡開車」的無腦心態忽略大環境轉變風險。

Summary (內容摘要)

節目開頭提及贊助商 Backbone 十週年優惠，結帳輸入優惠碼 GOOOA12026 可享工學椅、升降桌等配件全館 92 折，活動至 1 月 31 日截止；同時分享跨年抽手遊《勝利女神：妮姬》白雪公主角色與平淡度過新年的生活感悟。

針對盤勢分析，量化與鎖漲停交易圈反映散戶買盤已全面回流。雖然大盤表現極度強勢，但近期出現關鍵轉折訊號：過往被視為長多不敗的市場 Top Pick（如健策、貿聯、智邦、台光電及日前鴻勁）同步出現重摔。市場短線常以「貿聯受 Cable-less 設計影響」或「台光電 M9 材料未被採用」等理由解釋，但邏輯多有矛盾（如貿聯非做 In-rack cable、相關石英砂類股未跌）。講者判斷此現象主要源於大戶與法人資金偏好的輪動與提款轉換，而非單純基本面惡化。

在科技趨勢方面，NVIDIA 宣布 Vera Rubin（VR）晶片端進入 Full Production，後段上線預計於 2026 年年中以後，晶體管增加 2 倍但效能提升 10 倍，印證全機櫃（Full-rack）系統設計已取代傳統摩爾定律成為算力倍增核心。此外，更具破局思維的是 NVIDIA 推出由 BlueField DPU 驅動的 Inference Context Memory Platform (ICMS)，將戰線由運算、交換器延伸至儲存伺服器（DPU Storage Server）。

展場資訊顯示，NVIDIA Switch Tray 採用群聯（Phison）控制晶片，並將 TLC 顆粒轉為 pSLC（Pseudo-SLC）運作，將 512GB 縮減為 160 至 170GB 使用，以因應高頻讀寫耐用度。此架構的核心邏輯在於：Agentic AI 需要大量上下文推理（Reasoning），導致 KV Cache 佔用過多昂貴的 HBM 與 CPU RAM 資源並引發 AI 斷片。NVIDIA 透過 DPU 搭配 GPU Direct Storage，將準熱資料（Near-hot data）下放至專屬 SSD 暫存，大幅節省算力與電力消耗。對於投資人而言，記憶體與儲存族群不應僅視為原廠減產或報價漲價的週期題材，而應關注 KV Cache 下放結構性應用的全新投資機會。

在聽眾問答環節，講者針對產業報告撰寫提出建議，強調專業報告價值在於解析新應用對供應鏈的顛覆（如 ICMS 對 Storage Server 的影響、DDR4 轉 DDR5 的 ReDesign 零組件需求），而非重複已知的財務報價通識。對於投資操作，講者警告勿將過去十年台股多頭視為理所當然而盲目信貸開槓桿買正 2；在人際與職場處世上，則秉持「關我屁事」原則與相信直覺，避免公親變事主介入他人複雜家務事。
