AI 摘要報告

Key Takeaways (重點整理)

  • AI 算力重心擴散至伺服器 CPU：市場焦點從 GPU 延伸至 CPU 與客製化 ASIC。Nvidia 入股 RISC-V 架構公司 SiFive，且 AWS 傳出 Graviton CPU 算力遭客戶爭相全包卻因自用不足而拒絕，預示 Amazon 將擴大投片，Intel 與 AMD 等通用 CPU 廠商亦將迎來強勁需求。
  • 被動元件迎來新一波結構性缺貨與漲價潮：鉭質電容（Tancap）與鋁電容（SPCAP）嚴重缺貨，高階 MLCC（如村田、SEMCO）逼近警戒線。龍頭廠國巨與旗下基美（KEMET）下季度持續調漲價格，產業邏輯類似 2017 年需求爆發期。
  • AI 模型商行銷話術背後的核心真相是「算力嚴重不足」：Anthropic 宣稱新模型 Mythos 因「過於強大危險」暫不對外開放，實質原因是算力供給不足以支撐大規模調用，硬體供應鏈（台積電、先進封裝及晶片端）長線需求依然呈現無底洞狀態。
  • 光通訊極度缺產能引發台股「借殼代工」特殊現象：美系大客戶因擴廠不及，直接出資購買設備進駐台灣具備閒置 SMT 產能的廠商（如 LED 打件廠、網通廠）代工，目前台股已有約 4 檔標的出現此轉機題材，惟毛利偏低（約 10% 上下）且具抽單風險。
  • 大部位動能交易核心守則：當單一持股佔比拉高至 20%-30% 成最大分點時，「拉起不破、再軟必砍」是保護流動性與利潤的唯一法則，寧可賣在跌勢初期，絕不承擔流動性枯竭被鎖死跌停的風險。

Summary (內容摘要)

講者首先分享戒菸與生活觀察，指出吸菸帶來的快感本質上來自「高壓情境後的深呼吸與空間轉換」，若能抽離尼古丁、保留深呼吸習慣即可大幅降低戒斷痛苦；同時觀察到新世代（2000 年後）生活界線清晰、減少酒精依賴，展現更純粹的生活態度。

在美股與總體市場方面，第二季投資組合藉由資金輪動至 CPU、Marvell、光通訊及高速傳輸介面，績效迅速攻破新高。AI 運算除 GPU 算力外，需要大量 CPU 作為調度教練，加上 AWS Graviton 產能供不應求，確認伺服器 CPU 成為明確的結構性成長主線。針對近期 AI 軟體股遭到拋售與 Anthropic 暫緩釋出 Mythos 模型，講者直言市場過度充斥 FUD（恐懼、疑惑）情緒，模型商宣稱的危險性多為行銷包裝，核心瓶頸在於算力供給吃緊，這意味著晶圓代工與先進製程封裝等軍火商將持續受惠。

台股題材部分，被動元件產業交期（Lead Time）持續拉長，國巨法說會預期全面正向，高階 AI 應用帶動鉭電與鋁電嚴重缺料並啟動漲價；此外，光通訊強勁需求促使美系客戶自帶設備進駐台灣二線 SMT/LED 閒置產線代工，為低基期廠商帶來轉機，但投資人應留意驗證與訂單延續風險。最後，在動能操作上，講者強調「永遠以基本面為底氣、以破新高型態為進場訊號」，並在流動性風險浮現時果斷停損，切勿與市場硬碰硬。

Action Items (待辦事項 / 關鍵行動)

  • 追蹤國巨（Yageo）週三法說會：密切確認下季度產品報價調漲幅度、基美（KEMET）鉭電交期，以及高階 AI MLCC 產能利用率數據。
  • 佈局伺服器 CPU 與 ASIC 供應鏈：持續持有並關注 Server 端 CPU 相關標的（包括 Intel、AMD 及 RISC-V 概念），並檢視 AWS 供應鏈後續擴大投片之受惠廠商。
  • 嚴格執行技術面破線與流動性風控：當持股盤中出現「第一波下殺拉回無力、第二次轉弱破底」訊號時，必須即刻啟動減碼與停損，避免重倉陷入流動性陷阱。
  • 謹慎評估光通訊 SMT 外溢概念股：對於非本業接獲光通訊打件訂單的 4 檔轉機股，切勿盲目提前通靈佈局，應待股價轉強、確認實質營收與客戶驗證進度後，再列為次要順位參與。
